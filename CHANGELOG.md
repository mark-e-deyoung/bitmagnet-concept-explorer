# Changelog

## 0.0.1 — 2026-10-30

Initial preview release.

- Read-only Bitmagnet metadata query and bounded multilingual comparison UI, API, and CLI.
- Separate native facets, observed-result graph, provisional local concept preview, and opt-in SearXNG results.
- Basic Auth on network-facing routes; health endpoint is unauthenticated. Use a TLS-terminating reverse proxy for browser access.
- Nonroot scratch OCI image with a read-only-compatible runtime and health check.

Foundry target lifecycle, live Bitmagnet canary, accepted concept projection, and official catalog review are not included in this release.
