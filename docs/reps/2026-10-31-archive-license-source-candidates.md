# Internet Archive real torrent admission – bounded license-source experiment

**Independent workcell:** Research-only source-candidate extension to the already-qualified [real metainfo PR #18](https://github.com/mark-e-deyoung/bitmagnet-concept-explorer/pull/18). Do not modify the parent or merge drafts.

The earlier first-20 Prelinger probe admitted zero real `.torrent` objects under strict item-level public-domain source claims. This candidate adds two *official Archive search-index queries* for source-`licenseurl` public-domain and Creative Commons BY terms, preserving the Prelinger probe. Each stratum checks at most 12 identifiers from the official Advanced Search API; across strata at most 30 unique item metadata records are fetched, and at most two complete genuine `_archive.torrent` metainfo files are admitted. Only the existing bounded HTTPS `archive.org` fetch path is used.

Admission is fail-closed: exact item identifier and `mediatype=movies`; not dark; item-level `licenseurl` must be an actual Creative Commons public-domain dedication/mark or BY/BY-SA URL (no BY-NC/ND); item files must explicitly include format `Archive BitTorrent` with a matching `_archive.torrent` filename; downloaded content must be valid, nonprivate v1 metainfo under the size limit with genuine SHA-1 of original `info` bytes. A license URL is an **observed source claim**, not an independent global copyright or content clearance. Absent/contradictory license or missing torrent = no admission. No media payload or torrent peer/announce traffic.

The real ephemeral Bitmagnet/PostgreSQL/Explorer service reimports the qualified object list; optional Archive entries are recorded with exact source record, metainfo digest, real infohash and original URL. One inspectable native GHA artifact stores bounded source evidence for 14 days. The sample’s expected source volume is not fabricated, and **zero Archive objects is explicitly allowed as a source-coverage finding**, not a pass for Archive-specific full-stack qualification. No permanent storage, release, publication, permission promotion or CPE normative facts.

**Next join:** integrate only after independent exact-head GHA source+real-stack qualification. Once one Archive record is admitted, the dual-stack CPE sweep must run an **exact IA native-infohash query plus a separately labeled external reference lookup**, generate review-only `ConceptDiscoveryProposal` and run a held-out false-linkage challenge.
